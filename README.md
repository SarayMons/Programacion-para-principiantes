# Lenguajes De Programación

<mark style="background-color: #e9c1e4;">**Alto nivel**</mark>: es leguaje humanamente legible y lo más cercano a cómo los seres humanos hablamos.

<mark style="background-color: #e9c1e4;">**Bajo nivel**</mark>: lo más cercano al lenguaje nativo de la computadora.

# Términos


**1. <mark style="background-color: #e9c1e4;">Algoritmo:**</mark> Paso a paso para resolver un problema o lograr algo (pueden ser distintos pasos)

**2. <mark style="background-color: #e9c1e4;">Variable:**</mark> Espacio donde podemos almacenar datos, y estos datos pueden cambiar en un futuro.

**3. <mark style="background-color: #e9c1e4;">Palabra reservada:**</mark> Es una palabra que no podemos usar fuera de ese contexto.

**4. <mark style="background-color: #e9c1e4;">Comentario:**</mark> Bloque de código que no se ejecuta, pero es visible para nosotros como una nota.

**5. <mark style="background-color: #e9c1e4;">Dependencia:**</mark> Algo que su aplicación va a necesitar para funcionar.

**6. <mark style="background-color: #e9c1e4;">Funciones:**</mark> Serie de instrucciones, colocarle un nombre y ejecutarla de manera controlada.

**7. <mark style="background-color: #e9c1e4;">CamelCase:**</mark> Cuando es una frase la primera palabra comienza en minúscula y las que le siguen comienzan en mayúscula, un ejemplo claro es: **lowerCamelCase**.

**8. <mark style="background-color: #e9c1e4;">Tipos de datos:**</mark> Es decirle a la computadora qué tipo de contenido tiene una variable o constante. 

**9. <mark style="background-color: #e9c1e4;">Log:**</mark> Historial de sucesos.

**10. <mark style="background-color: #e9c1e4;">Warning:**</mark> Algo que no tiene la misma seriedad que un error, pero también se le debe prestar atención.

**11. <mark style="background-color: #e9c1e4;">Strings:**</mark> Almacenar carácteres.

**12. <mark style="background-color: #e9c1e4;">Numbers:**</mark> Almacenar números.

**13. <mark style="background-color: #e9c1e4;">Boolean:**</mark> Almacenar valores de verdadero y falso.


# Errores

**1. <mark style="background-color: #e9c1e4;">Sintaxis:**</mark> Usar mal una palabra reservada.

**2. <mark style="background-color: #e9c1e4;">Lógica:**</mark> Cuando nosotros nos equivocamos y la computadora intenta interpretar lo que quisimos decir.

# Reglas Sobre Nombres De Las Variables Y Constantes

**1.** No podemos darle el nombre a una variable o constante, igual a una palabra reservada del lenguaje de programación. 

**2.** Puedes usar letras, números y guión bajo para definir las variables y constantes (pero no puedes iniciar el nombre con un número).

**3.** No pueden contener caracteres especiales como: @ ( % ‘ # ! á é í ó ú ñ pero el signo $ sí es permitido igual que el guión bajo.
